Генерация ответа

При смене модели лимит автоматически становится 2048 токенов для DeepSeek или 1024 для локальной Ollama; его можно вручную изменить. Остальные параметры сохраняются. Если указан top_p, temperature не отправляется. Контекст локальной Ollama ограничен 8192 токенами.

Для сценария из 15 обменов установите N=32; полная история сохраняется, а память задачи помогает и при N=4.

В модель отправляются только последние N сообщений. Ранние реплики удаляются.

Reranking и фильтрация

Cosine-порог фильтрует vector candidates. Отдельный lexical-канал допускает совпадения минимум двух разных терминов; каналы объединяются до final top-K. Rerank — необязательный второй этап. Trace показывает канал и исходный cosine.
