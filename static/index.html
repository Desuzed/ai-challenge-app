Один запрос — четыре температуры

Нажмите «Запустить сравнение»: приложение четыре раза отправит один и тот же запрос. Меняется только temperature; top_p не используется, а лимит ответа остаётся одинаковым.

Пример запроса для эксперимента

Объясни школьнику в 2–3 предложениях, почему после дождя появляется радуга. Используй простой русский язык.

Факты для сверки: в хорошем объяснении должны быть капли воды, преломление, внутреннее отражение и разложение света на цвета.

temperature = 0

Наиболее предсказуемый и сдержанный вариант.

temperature = 0.7

Баланс точности и выразительности.

temperature = 1.2

Больше неожиданных формулировок и идей.

temperature = 1.8

Максимальная вариативность и самые смелые варианты.

Запуски идут последовательно, поэтому все четыре ответа используют одну и ту же формулировку запроса.
Что сравнивать в полученных ответах
  1. Точность: все ли факты верны и отвечает ли текст на запрос. Для примера с радугой проверьте четыре факта выше.
  2. Креативность: есть ли более оригинальные, понятные или образные формулировки, не подменяющие факты.
  3. Разнообразие: отличаются ли лексика, структура и примеры. Для честной оценки повторите каждый вариант 2–3 раза.

Типичные ответы и когда их использовать

Это иллюстративные примеры, а не предсказание конкретного запуска: даже при одинаковой температуре ответы могут различаться.

0 — стабильность

«Радуга возникает, когда солнечный свет проходит через капли воды. Свет преломляется, отражается внутри капли и распадается на цвета».

Подходит для: извлечения данных, классификации, инструкций, повторяемых ответов и черновиков кода.

0.7 — баланс

«Капли после дождя работают как маленькие призмы: солнечный свет преломляется, отражается внутри и превращается в цветную дугу».

Подходит для: диалогов, объяснений, писем и большинства обычных текстов.

1.2 — вариативность

«После дождя миллионы капель превращают небо в большой калейдоскоп: солнечный луч изгибается, отражается и раскладывается на цветную дугу».

Подходит для: идей, названий, сторителлинга и поиска многих вариантов; факты стоит дополнительно проверять.

1.8 — максимум свободы

«После дождя небо превращается в огромную палитру: солнечный свет ныряет в капли, преломляется, отражается внутри них и возвращается к нам цветной дугой».

Подходит для: свободного мозгового штурма, художественных образов и необычных концепций. Факты, расчёты и точные инструкции используйте только с обязательной проверкой.

Высокая температура повышает вариативность, но сама по себе не делает ответ неверным. temperature = 0 также не гарантирует фактическую истинность.

Тестовые данные для задания

Четыре задачи A, B, C и D нужно выполнить в четыре последовательных слота: 1, 2, 3, 4. A выполняется раньше B; C — сразу после A; B — сразу перед D. В каком порядке выполняются задачи? Кратко проверьте все условия.

Эталон для сверки: A → C → B → D. Не включайте его в сам запрос — он нужен только для оценки полученных решений.

Лимит ответа снят: для финального решения урока 3 сервер использует максимум API — 8192 токена. Ограничение 720 токенов действует только на короткий шаг создания рабочего промпта.

Прямой вариант создаёт базовую точку сравнения: оценивайте итог без дополнительного управления ходом решения.

Пакетный запуск сделает 5 API-вызовов: третий способ состоит из двух шагов.
Что именно сравнивать после запусков
  1. Совпадает ли порядок с эталоном A → C → B → D и соблюдены ли все три условия.
  2. Отличаются ли формулировки, полнота расчёта и проверка допущений.
  3. Какой верный ответ легче проверить: обычно полезны явные шаги или проверка критиком, но вывод делайте по фактическим результатам запуска.

Сравнение решений

Запустите хотя бы один способ в третьем табе.

Как выбрать наиболее точный результат

Сначала исключите ответы, не совпадающие с эталоном. Среди совпавших предпочтите тот, где верно учтено условие, виден проверяемый расчёт и нет лишних неподтверждённых допущений.

Ключ DeepSeek находится только на сервере и не передаётся в браузер или журнал.
