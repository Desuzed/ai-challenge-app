# Контрольные вопросы по локальной базе

Задавайте один и тот же вопрос с выключенным и включённым «Поиск по документам (RAG)». Для чистого сравнения используйте одинаковую модель и пустую историю перед каждым запуском; выключите планировщик в дашборде плана. В техническом журнале сверяйте `contextSentToModel`, `ragSources` и ответ. Отметьте, выполнено ли ожидание для каждого режима. Наличие источника в выдаче само по себе не доказывает правильность ответа.

| № | Вопрос | Что должно быть в ответе | Ожидаемые источники | Без RAG | С RAG |
|---|---|---|---|---|---|
| 1 | Где приложение хранит историю диалога агента между перезапусками? | В локальном JSON-файле `.local/agent-history.json`. | `README.md` |  |  |
| 2 | Что имеет приоритет для `DEEPSEEK_API_KEY`: окружение процесса или `.env`? | Непустое значение из окружения процесса; `.env` читается, когда его нет. | `main.go` |  |  |
| 3 | Какой маршрут браузер использует для сообщения основному агенту? | `POST /api/agent/chat`; обработчик вызывает агента с настройками запроса. | `README.md`, `internal/handlers/handlers.go` |  |  |
| 4 | Какие два способа разбиения документов реализованы в индексаторе? | Фиксированные окна по 1200 символов с перекрытием 150 и разбиение по заголовкам Markdown/объявлениям Go. | `README.md` |  |  |
| 5 | Где сохраняются два индекса и отчёт? | В `.local/rag/`: `index-fixed.json`, `index-structure.json`, `report.json`. | `README.md` |  |  |
| 6 | Какую информацию об источнике, файле, разделе и идентификаторе хранит каждый чанк локального индекса? | `source`, `title`, `section`, `chunk_id`; также текст и эмбеддинг. | `README.md` |  |  |
| 7 | Какие четыре MCP-сервера собираются в единый каталог при старте приложения? | Яндекс Диск, GitHub, погода и новости. | `main.go` |  |  |
| 8 | Как соединены MCP-сервер и клиент внутри приложения? | Через in-memory transport, без второго HTTP-сайта и отдельного процесса. | `README.md` |  |  |
| 9 | Какой период сбора погоды используется при отсутствии настройки интервала? | Одна минута. | `main.go` |  |  |
| 10 | Куда уходит API-ключ DeepSeek и виден ли он браузеру? | Ключ остаётся на Go-сервере и передаётся DeepSeek в заголовке `Authorization`; браузер его не получает. | `README.md` |  |  |

Оценка: поставьте `1`, если ответ содержит ожидаемый факт без противоречий, иначе `0`. Для режима RAG отдельно проверьте, что найден хотя бы один ожидаемый файл и ответ ссылается на него. Сумма по десяти вопросам покажет разницу качества на этой базе.
