# Модели и генерация

## Провайдеры

Основной чат использует `internal/llmrouter`. Идентификаторы `deepseek-flash` и `deepseek-v4-pro` направляются к DeepSeek. `ollama/<имя>` использует локальную Ollama, `ollama-remote/<имя>` — отдельный сервер. Каталог Ollama запрашивается у соответствующего подключения; приложение не обещает наличие модели, которую сервер не вернул.

OpenRouter используется отдельным режимом сравнения моделей. Наличие клиента OpenRouter не означает, что все его модели доступны в основном чате. Цены и доступность провайдеров могут меняться; смотрите метрики фактического ответа.

## Параметры

| Поле | Смысл |
|---|---|
| `temperature` | Вариативность выбора токенов |
| `topP` | Ограничение вероятностного ядра |
| `maxTokens` | Бюджет выходных токенов |
| `contextWindow` | Окно Ollama; поддерживаемый диапазон приложения 512–32768 |
| `topK` | Ограничение выбора токенов Ollama; 1–1000 |
| `seed` | Seed Ollama; влияет на воспроизводимость, но не гарантирует её на разном оборудовании |
| `repeatPenalty` | Штраф за повтор токенов Ollama; 0–2 |
| `localThink` | Запрос режима рассуждений Ollama |
| `localJson` | JSON-формат обычного ответа Ollama |

Отправляйте temperature или topP. Интерфейс при заданном topP не передаёт temperature; backend отклоняет одновременное указание обоих. Генерационный topK не связан с количеством фрагментов в RAG.

Начальный бюджет основного чата: 2048 токенов для API, 1024 для локальной Ollama. Для удалённой Ollama maxTokens и contextWindow могут оставаться пустыми, тогда приложение не отправляет эти ограничения. Это настройки приложения, а не утверждение о предельных возможностях моделей.

## Формат и доказательства

JSON-режим ограничивает форму ответа, но не доказывает правильность значений. RAG использует отдельный структурированный формат claims с цитатами. Сервер проверяет эти цитаты независимо от выбранного провайдера.

Для локального RAG приложение задаёт JSON Schema и отключает рассуждения, чтобы бюджет не ушёл на них до финального ответа. Для небольших бюджетов предусмотрен компактный формат и одна повторная попытка при обрезании JSON или пустых claims. Фактический бюджет, попытки, finish reason и usage отображаются в журнале.

## Метрики и диагностика

В основном чате запрос DeepSeek ограничен 60 секундами вместе с поиском и возможной повторной генерацией. При таймауте во время чтения тела ответа сервер возвращает HTTP 504; ошибки HTTP провайдера сообщаются отдельно. Интерфейс показывает время ожидания и текст ошибки в журнале. Если сервер перестал отвечать, браузер прекращает ожидание API-запроса через 75 секунд. Для локальной Ollama, удалённой Ollama и `/reindex` действуют отдельные лимиты.

`localMetrics` содержит время Ollama и производительность выходных токенов. Token report разделяет оценку контекста, фактический usage и резерв ответа. Число символов не равно числу токенов. Высокая temperature увеличивает вариативность; низкая не гарантирует истинность.

```sh
python3 scripts/check_local_llm.py --check
python3 scripts/check_local_llm.py --prompt "Объясни разницу между памятью и диском."
```

Диагностический скрипт сохраняет реальные запросы и ответы локально. Автоматический A/B runner `scripts/benchmark_local_settings.py` работает через основной chat API; его 12 наборов входов теперь лежат в `scripts/fixtures/local-model-cases.json`. Fixture отделена от RAG-корпуса. Для сравнения используйте чистые сессии, одинаковые вопросы и один изменяемый параметр.
