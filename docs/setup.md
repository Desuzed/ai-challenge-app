# Запуск и конфигурация

## Локальный сервер

Приложение — Go web-сервис с обычным HTML/JavaScript интерфейсом. Требуется Go 1.25 или новее. Запускайте команды из корня репозитория, поскольку пути к интерфейсу, конфигурации, истории и RAG определяются относительно рабочего каталога.

```sh
cp .env.example .env
chmod 600 .env
go run .
```

По умолчанию адрес — `http://localhost:8080`, привязка — `127.0.0.1`. Другой порт: `PORT=8090 go run .`. Завершение — Ctrl+C.

## Настройки окружения

| Имя | Назначение и значение по умолчанию |
|---|---|
| `DEEPSEEK_API_KEY` | Ключ DeepSeek; без него облачная генерация недоступна |
| `OLLAMA_URL` | Локальная Ollama; `http://127.0.0.1:11434` |
| `REMOTE_OLLAMA_URL` | Отдельный сервер Ollama; пустое значение выключает источник |
| `GITHUB_REPOSITORY` | GitHub-репозиторий; `Desuzed/ai-challenge-app` |
| `GITHUB_TOKEN` | Токен GitHub для приватного чтения или записи |
| `YANDEX_DISK_OAUTH_TOKEN` | OAuth-токен Яндекс Диска |
| `YANDEX_DISK_ROOT` | Корневая папка Диска; `AI Challenge` |
| `VIDEO_SOURCE_DIR` | Папка видео; `~/Desktop` |
| `WEATHER_DATA_FILE` | JSON измерений погоды; `.local/weather-observations.json` |
| `WEATHER_COLLECTION_INTERVAL_SECONDS` | Начальный период сбора в секундах; положительное значение, по умолчанию 60 |
| `AGENT_HISTORY_FILE` | Файл состояния агента; `.local/agent-history.json` |
| `PORT` | Порт HTTP-сервера; `8080`; читается из окружения процесса |

Для подключений непустое значение окружения процесса имеет приоритет над `.env`. Файл `.env` читается сервером. `PORT` читается только из окружения процесса. Изменение погодного расписания через MCP допускает 60–86400 секунд.

Ключ DeepSeek передаётся провайдеру только в заголовке `Authorization`. Браузер работает с локальным backend и не получает секрет. Шаблон `.env.example` можно хранить в Git, рабочий `.env` — нет. Локальные журналы и состояние также исключены из Git.

## Ollama и индекс

Запустите Ollama и установите нужные модели:

```sh
ollama pull embeddinggemma
ollama pull qwen3:4b
go run ./cmd/indexdocs -root .
```

`embeddinggemma` создаёт векторы поиска; `qwen3:4b` — пример модели для ответа. Установленная модель и её пригодность должны проверяться на конкретном компьютере. Если локальная Ollama использует другой адрес, задайте `OLLAMA_URL` для приложения и передайте тот же адрес индексатору: `-ollama-url http://адрес:11434`.

## Отдельный сервер Ollama

Укажите `REMOTE_OLLAMA_URL=http://адрес:11434` и перезапустите backend. Модели появятся в группе удалённого источника. Их идентификаторы имеют префикс `ollama-remote/`; локальные — `ollama/`. Одинаковое имя модели в двух источниках не делает их одним подключением.

Приложение проверяет доступность каталога при открытии выбора модели. Сбой удалённого сервера не отключает локальный каталог. Доступность сети и разрешения сервера на LAN настраиваются на стороне Ollama. Лимиты генерации и контекста удалённой модели изначально не заданы: при пустых настройках используются значения сервера.
