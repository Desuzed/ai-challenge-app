## Обновление документации

Изменяйте соответствующий тематический раздел вместе с кодом. README остаётся точкой входа: назначение, быстрый запуск и структура. Примеры запросов должны соответствовать типам `internal/models/models.go` и обработчикам, а список MCP — регистрации инструментов.

После изменения документации запускайте `go run ./cmd/indexdocs -root .`. Файлы Markdown, TXT, JSON и YAML внутри `docs` включаются рекурсивно. Секреты, отчёты и тестовые фикстуры храните за пределами документационного корпуса. Проверяйте ссылки и актуальность хешей индекса перед проверкой ответов.
